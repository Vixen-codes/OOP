# Object-Oriented Programming (Java)

Practical exercises and problem sets in Java from my first-year Software Engineering and Object-Oriented Programming module at the University of Surrey.

## Contents

| Folder | Contents |
| --- | --- |
| `Practicals/` | Weekly lab exercises |
| `ProblemSets/` | Longer problem sets |

## Topics covered

Classes and objects, encapsulation, inheritance and polymorphism, interfaces, collections and unit testing in Java.
